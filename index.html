👋 Для синхронизации между устройствами нужна бесплатная Firebase база данных.

1. Открой console.firebase.google.com → Add project
2. В проекте: Build → Realtime Database → Create database → Start in test mode
3. Скопируй URL базы (похоже на это):
https://ИМЯ-ПРОЕКТА-default-rtdb.europe-west1.firebasedatabase.app

4. Вставь URL сюда и нажми Сохранить — и всё!
